# Night Arcade

A small, black-themed games website featuring **Neon Square**, a playable arcade game.

## Run it

Open `index.html` in a modern web browser. No build tools or dependencies are required.

## Play

Use the left and right arrow keys or **A / D** to move the square and dodge the falling blocks. On touch screens, use the on-screen arrow buttons. Your best score is saved in the browser when storage is available.
